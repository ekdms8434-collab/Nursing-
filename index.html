취업 연관성 상세 분석

졸업 코호트별 비교과 이수와 취업 현황의 연관성을 살펴보세요.

원본 엑셀은 이 컴퓨터의 로컬 서버에서만 처리합니다. 외부 AI에는 검토·확인한 보호 집계만 전송합니다. 실제 학생 자료 사용과 외부 집계 전송은 기관의 개인정보 처리·보안 승인을 먼저 받으세요. API 키를 파일이나 화면에 입력하지 마세요.

서버 연결을 확인하세요.

1. 엑셀 파일 업로드

XLSX만 지원 · 파일당 8MB / 전체 20,000행 · 첫 행은 열 제목 · 수식은 값으로 변환 · 병합 제목행은 제거하세요. 학번은 텍스트로 저장하고 앞자리 0을 유지하세요. 파일당 한 시트를 분석합니다.

2. 시트·열 지정 및 학번 대조

참석/이수 명단

졸업생 취업현황

취업상태 열은 병원 유형·미취업·미확인이 구분된 열을 선택하세요. 상태와 병원 유형이 별도 열이라면 먼저 하나의 분류 열로 정리하세요. 각 상태값은 정확히 일치해야 하며 미지정·공백 값은 미확인으로 집계됩니다.


            

            
            
          

          

          

            
3. 대조 결과 · 집계 검토
‘기록 없음’은 제출한 명단에 해당 학번의 기록이 없다는 뜻이며 미이수 확정이 아닙니다. 다른 파일·누락 과정의 영향을 확인하세요. 취업현황 중복·학번 누락은 분석을 차단하며 명단 중복은 학번+과정 기준으로 제거합니다. 결과와 원본은 브라우저 저장소·서버 디스크에 저장하지 않으며 서버 메모리 자료는 20분 후 만료됩니다.

            
4. Gemini 전송 집계 미리보기
원본·학번·이름·자유 입력 과정명·코호트는 전송하지 않습니다. 5명 미만의 비영 셀이 있으면 해당 집계를 제외합니다. 여러 집계의 교차 추론을 줄이기 위해 전체 및 안전한 과정 분할 최대 1개만 전송합니다. 조합/코호트별 상세는 로컬 보고서에만 포함합니다. 이는 완전한 익명성을 보장하지 않습니다.

            
5. AI 해석 초안
생성형 AI는 오류가 있을 수 있습니다. 수치·해석을 로컬 집계와 대조하고 담당자가 검토한 뒤 사용하세요. 공식 통계·자동 의사결정 자료가 아닙니다.
